# Gtk-OSX #

This fork of https://github.com/jralls/gtk-osx-build is used to build
https://github.com/Xpra-org/xpra on MacOS.

For usage, please refer to the upstream documentation.

As of 2026-10-15, keep OpenSSL on 3.5.x, Python on 3.14.x, and Paramiko on
4.x until these branch holds are explicitly revisited. Updates within those
branches are welcome; do not move to a newer branch automatically.
